## Overview

**Vietnam Stock Data Analysis Terminal (VSDAT)** is a fullstack data analytics web application for analyzing Vietnamese stock market data.

The application allows users to enter a Vietnamese stock symbol such as `VIC`, `FPT`, `MBB`, or `VNM`. The backend retrieves historical OHLCV data from `vnstock / vnstock3`, processes it with `Pandas` and `NumPy`, calculates technical indicators, generates reference trading signals, and returns structured JSON data to the frontend.

The frontend presents the result as a dark-themed analytical dashboard built with `React`, `Tailwind CSS`, and `Recharts`. Users can also export historical stock data into a formatted Excel report generated by `OpenPyXL`.

This project is designed as a **Data Analytics + Fullstack Web App portfolio project**, suitable for demonstrating skills in data collection, data cleaning, time-series analysis, dashboard visualization, API development, and automated reporting.

## Project Motivation

The purpose of VSDAT is to demonstrate an end-to-end data analytics workflow in a practical business-style project.

Instead of only showing static charts or a simple notebook, this project converts stock market data into an interactive web application with:

- Automated data retrieval
- Data cleaning and transformation
- Time-series indicator calculation
- Risk and reference level analysis
- Dashboard visualization
- Excel export for further analysis
- Modular backend and frontend architecture

From a portfolio perspective, VSDAT shows that the developer can work across the full analytics pipeline, from raw market data to user-facing insights.

## Key Features

### 1. Vietnamese Stock Symbol Search

- Users enter a stock symbol such as `VIC`, `FPT`, `MBB`, or `VNM`.
- The frontend automatically removes extra spaces and converts symbols to uppercase.
- The frontend calls the backend API to retrieve stock analysis data.

### 2. Latest Price Summary

The dashboard displays:

- Current price or latest available price
- Reference price or previous close
- Price change
- Percentage change
- Status: `up`, `down`, or `unchanged`
- Color mapping: green, red, or yellow

### 3. Technical Analysis Indicators

The backend calculates:

- `MA20`
- `MA50`
- `MA100`
- `MA200`
- `RSI 14`
- `MACD`
- `MACD Signal`
- `MACD Histogram`
- `Bollinger Upper Band`
- `Bollinger Lower Band`
- `Average Volume 20 sessions`

### 4. Support and Resistance Analysis

The system estimates:

- Nearest support level
- Nearest resistance level
- Distance to support in percentage
- Distance to resistance in percentage

This helps users understand whether the current price is close to an important technical level.

### 5. Risk Management Reference Levels

The backend generates reference levels for:

- Entry zone
- Stop loss
- Take profit zone
- Risk/Reward Ratio

These values are for learning and data analysis practice only. They are not trading advice.

### 6. Reference Signal Engine

VSDAT provides a reference technical signal:

- `BUY`
- `WATCH`
- `HOLD`
- `SELL`
- `CUT_LOSS`

The signal is calculated from multiple factors such as trend, RSI, MACD, volume, support and resistance, VNINDEX condition, and Risk/Reward Ratio.

The signal is not a guaranteed prediction and must not be interpreted as financial advice.

### 7. Suggested Order Reference

The app can display reference order information such as:

- `LO`
- `WAIT_BUY`
- `BUY_LIMIT`
- `SELL_LIMIT`
- `CUT_LOSS`

The application prioritizes `LO` limit orders in the explanation because limit orders are easier for beginners to understand and control. This section is for educational purposes only.

### 8. VNINDEX Market Context

If VNINDEX data is available, the backend analyzes general market context:

- VNINDEX price
- VNINDEX change percentage
- VNINDEX MA20
- VNINDEX trend: `UP`, `DOWN`, `NEUTRAL`, or `UNKNOWN`
- Market condition: `GOOD`, `NORMAL`, `BAD`, or `UNKNOWN`

If VNINDEX data cannot be retrieved, the backend safely returns `UNKNOWN` without crashing the application.

### 9. Interactive Dashboard

The frontend includes:

- Current price card
- RSI card
- MA20 card
- Main signal card
- Risk management card
- Support and resistance card
- Market condition card
- Suggested order card
- Positive reasons checklist
- Warning checklist
- Technical metrics card
- Price, volume, and moving average chart
- RSI chart
- MACD chart

### 10. Excel Export

Users can select a start date and end date, then export historical stock data to a formatted `.xlsx` file.

The exported file includes:

- Date
- Open price
- High price
- Low price
- Close price
- Price change
- Percentage change
- Volume

The Excel file includes formatted headers, number formatting, and developer contact information.

## Data Analytics Workflow

VSDAT follows a practical data analytics pipeline:

```text
[User Input]
Stock symbol and optional export date range

[Data Ingestion]
Backend retrieves historical OHLCV data using vnstock or vnstock3

[Data Cleaning]
Pandas standardizes time columns, numeric columns, price units, and missing values

[Data Transformation]
Backend calculates price change, percentage change, MA, RSI, MACD, Bollinger Bands, and average volume

[Analytical Layer]
Backend estimates support, resistance, risk management levels, VNINDEX context, and reference signals

[API Layer]
Flask returns structured JSON to the React frontend

[Visualization Layer]
React, Tailwind CSS, and Recharts display KPI cards, checklists, and charts

[Reporting Layer]
OpenPyXL exports clean historical data into a formatted Excel workbook
```

This workflow reflects common Data Analyst responsibilities: collecting data, cleaning data, transforming data, building metrics, visualizing insights, and delivering reports.

## System Architecture

```text
Frontend: React + Vite + Tailwind CSS + Recharts
        │
        │ HTTP request with Axios
        ▼
Backend: Flask API + Flask-CORS
        │
        ├── Stock data service
        ├── Technical analysis service
        ├── VNINDEX market service
        ├── Risk management utility
        ├── Support and resistance utility
        └── Excel export service
        │
        ▼
Data Source: vnstock / vnstock3
        │
        ▼
Processed Output: JSON dashboard data or Excel file
```

The project uses a decoupled client-server architecture:

- The frontend is responsible for UI, user interaction, API calls, and data visualization.
- The backend is responsible for data retrieval, data processing, technical analysis, signal calculation, and Excel generation.
- There is currently no database. Data is retrieved from stock data libraries and processed on request.

## Getting Started

### Prerequisites

Install the following tools before running the project locally:

- Python 3.10 or higher
- Node.js 18 or higher
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/tuanda2309/Vietnam_Stock_Data_Analysis_Terminal_VSDAT.git
cd Vietnam_Stock_Data_Analysis_Terminal_VSDAT
```

### 2. Run the Backend

```bash
cd backend
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Activate the virtual environment on macOS or Linux:

```bash
source venv/bin/activate
```

Install backend dependencies:

```bash
pip install -r requirements.txt
```

Start the Flask backend:

```bash
python app.py
```

Backend URL:

```text
http://127.0.0.1:5000
```

Test an API endpoint:

```text
http://127.0.0.1:5000/stock/VIC
```

### 3. Run the Frontend

Open a new terminal from the project root:

```bash
cd frontend
npm install
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```
